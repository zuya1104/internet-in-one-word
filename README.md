One word for the whole internet, funniest and most fitting wins.

## Entry

**Enshittification**

The single word that describes the whole internet: every platform,
search engine, feed and app slowly getting worse as it squeezes its
users for more — the defining story of the internet today.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly that one
word to `/output/entry.txt` — no trailing newline, no extra text, no
files, no links. The sealed gate requires UTF-8 text of 1 to 30
characters; the entry is 16 characters.

## Run

```sh
python3 main.py
```
